# AI Productivity Dashboard

A full-stack AI productivity dashboard built using React, Node.js, Express, and MongoDB.

## Features

- AI Text Summarization
- Authentication System
- Summary History
- Responsive Dashboard UI
- REST API Integration

## Tech Stack

Frontend:
- React
- Vite
- CSS

Backend:
- Node.js
- Express.js
- MongoDB

## Installation

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm start
```

## Environment Variables

Create `.env` inside server folder:

```env
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret
OPENROUTER_API_KEY=your_api_key
```
